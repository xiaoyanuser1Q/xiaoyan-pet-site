🌸 小桃养成记 · 隐私政策

生效日期 2026-10-27 · 适用版本 v1.3.0 起（v1.2.0 及更早版本不申请以下新权限）

一、APP 权限说明（v1.3.0 新增两项）

  • 安装未知应用（REQUEST_INSTALL_PACKAGES）：仅用于「APP 内下载安装更新包」功能。你点「下载 → 安装」时，系统会询问一次是否允许本 APP 安装应用；拒绝或后续关闭都不影响游戏本体玩法，更新包可改由官网浏览器下载。
  • 通知（POST_NOTIFICATIONS，Android 13+）：仅用于本地提醒（发现新版本 / 小桃升级 / 跨幕提醒），不发任何联网推送。Android 13 以下设备（如 Android 10）不会弹出此权限请求，通知直接可用；可随时在系统设置或 APP 设置页关闭。
  • 两项权限均不读取你的任何数据，权限授予情况本身也不会上报。

一、我们收集什么

  • 不收集：设备型号、位置、通讯录、任何广告追踪数据。APP 无广告、无内购、无第三方统计 SDK。
  • 账号（可选）：启用云存档时，经 Supabase 保存你的邮箱地址与加密密码（由 Supabase 官方存储，我们看不到明文）。
  • 云存档：你主动点「同步到云」时，把游戏存档上传到你自己的 Supabase 账号（仅本人可读写，RLS 策略隔离）。
  • 登录事件：登录成功时写一条 event_logs 记录（账号 ID + 版本号 + 时间），用于问题排查。

二、本地数据

  • 游戏存档、设置、云账号 token 均只存在本设备 APP 私有目录。
  • 本地数据不参与 Android 系统备份（manifest 已设 allowBackup=false）。

三、第三方

  • Supabase（云存档与账号，wigjusjcgjajpnxg…）
  • Cloudflare（官网静态页分发 + 网络代理 Worker）
  • agnes-ai.com（仅开发阶段生成 AI 立绘使用，APP 运行中不连接）

四、素材说明

全部人物立绘由 AI（Agnes 画室）生成；背景与音频为程序化生成，均无第三方版权素材。详见官网仓库 CREDITS。

五、你的权利

  • 随时在 APP 设置页删除云存档、退出登录。
  • 随时在 Supabase 后台删除账号与全部数据。
  • 问题反馈 / 数据请求：通过 Gitee 仓库 或 GitHub 仓库 提 Issue 联系宵檐。
